How this works

Each item and target level has its own list of results. The list is fixed in advance by a starting seed, which comes from the character name, the item and the level. Every attempt on that step uses the next unused result, whether it succeeds or fails, and the game saves its place in the character file. Reloading cannot change a result, so the next ones can be read ahead of time.

An upgrade succeeds when the roll is 0.65 or less, and a failure destroys the item. That value comes from the game data as read by Melichor's ValheimSaveParser, and it fits all 26 attempts we recorded on Valheim 1.0.20: 14 hammer attempts, and 12 on three copies of the same chest.

The list belongs to the item type and level, not to one copy. A second copy of the same item uses the next unused result on each step the first copy reached, and the 1st result on steps it did not reach. Use "Results to show" to see the 2nd and 3rd results side by side. Rows after the first assume every earlier step succeeded, because a failure breaks the item.

With a save loaded, the page reads each step's place from the file, so quit to the main menu after any attempt, because the game only writes seeds when it saves. Without a save, for example on console, every step starts from the character name, so enter how many attempts the character has already made on each step. The name has to match exactly, including capitals. This has been tested on PC saves only.
